# 실시간 코드 리뷰 에이전트가 신입 개발자의 학습 전이에 미치는 영향: 12주 현장 연구

김도현, 정하나, 오세진, B. Lindqvist — 서울과학기술대학교 인간-컴퓨터 상호작용 연구실 (사전공개본, 동료심사 이전)

## 초록

본 연구는 실시간 코드 리뷰 에이전트를 도입한 신입 개발자 팀에서 코드 품질 지표와 학습 전이가 어떻게 변화하는지를 12주 동안 관찰했다. 국내 3개 기업의 신입 개발자 47명을 대상으로 한 준실험 설계에서, 에이전트를 사용한 집단은 대조 집단 대비 리뷰 반려율이 34.2% 감소했고(p = 0.008), 동일 유형 결함의 재발률이 21.7% 감소했다. 그러나 에이전트 없이 수행한 12주차 전이 과제에서는 두 집단의 결함 밀도 차이가 통계적으로 유의하지 않았다(p = 0.31). 우리는 실시간 에이전트가 산출물 품질을 즉각적으로 개선하지만, 도구가 없는 상황으로의 학습 전이는 관찰 기간 내에서 확인되지 않았다고 결론짓는다.

## 1. 서론

코드 리뷰는 신입 개발자가 팀의 코딩 규범을 습득하는 주된 경로로 알려져 있다. 최근 도입된 언어모델 기반 리뷰 에이전트는 사람 리뷰어보다 훨씬 빠른 주기로 피드백을 제공하며, 이로 인해 결함이 조기에 제거된다는 보고가 이어지고 있다.

그러나 산출물 품질 개선과 학습은 구분되어야 하는 결과다. 교육 연구에서 즉각적 피드백은 수행을 높이지만 전이를 반드시 높이지는 않으며, 오히려 학습자가 외부 단서에 의존하게 되는 현상이 반복적으로 보고되어 왔다. 소프트웨어 개발 현장에서 이 구분을 직접 측정한 연구는 드물다.

본 연구의 질문은 다음과 같다. 실시간 리뷰 에이전트를 사용한 신입 개발자는 에이전트가 없는 조건에서도 더 나은 코드를 작성하는가?

## 2. 관련 연구

자동 정적 분석 도구의 효과를 다룬 선행 연구는 결함 검출률 개선을 일관되게 보고하지만, 개발자의 지식 변화를 측정한 사례는 많지 않다. 교육 심리학의 피드백 타이밍 연구는 즉각 피드백이 절차적 기능 습득에는 유리하고 개념적 전이에는 불리할 수 있음을 시사한다. 프로그래밍 교육 연구에서는 힌트 제공 시스템 사용자가 힌트 제거 조건에서 성능이 하락하는 이른바 도움 남용 현상이 보고되었다.

## 3. 방법

### 3.1 참여자와 설계

국내 3개 기업(각각 백엔드 서비스, 금융 플랫폼, 커머스 도메인)의 입사 1년 미만 개발자 47명이 참여했다. 팀 단위 배정을 사용해 5개 팀 24명을 실험 집단, 4개 팀 23명을 대조 집단으로 배정했다. 무작위 배정이 아니라 기업의 배포 일정에 따른 준실험 배정이다.

### 3.2 개입

실험 집단은 12주 동안 풀 리퀘스트 생성 시점에 자동으로 실행되는 리뷰 에이전트의 피드백을 받았다. 에이전트는 결함 지적, 근거 설명, 수정 제안을 함께 제시했다. 대조 집단은 기존과 동일하게 사람 리뷰만 받았다. 두 집단 모두 사람 리뷰 절차는 변경하지 않았다.

### 3.3 측정

주 결과 변수는 세 가지다. 첫째, 리뷰 반려율은 사람 리뷰어가 변경 요청을 남긴 풀 리퀘스트의 비율이다. 둘째, 동일 유형 결함 재발률은 이전에 지적받은 결함 유형이 이후 4주 내에 다시 발생한 비율이다. 셋째, 전이 성능은 12주차에 에이전트를 비활성화한 상태에서 수행한 표준 과제의 결함 밀도다.

전이 과제는 세 기업 공통으로 설계한 약 400줄 규모의 기능 구현 과제이며, 두 명의 평가자가 집단 정보를 모르는 상태에서 채점했다. 평가자 간 일치도는 Krippendorff 알파 0.79였다.

### 3.4 분석

기업과 팀을 임의효과로 포함한 혼합효과 모형을 사용했다. 팀 단위 배정이므로 개인 수준 표본 수가 아닌 팀 수가 유효 표본 크기에 가깝다는 점을 고려해 군집 보정 표준오차를 함께 보고한다.

## 4. 결과

실험 집단의 리뷰 반려율은 12주 평균 28.4%로, 대조 집단 43.2% 대비 34.2% 감소했다(p = 0.008, 군집 보정). 감소는 개입 2주차부터 나타나 이후 안정적으로 유지되었다.

동일 유형 결함 재발률은 실험 집단 18.9%, 대조 집단 24.1%로 21.7% 상대 감소했다(p = 0.04).

12주차 전이 과제에서 실험 집단의 결함 밀도는 1,000줄당 6.8건, 대조 집단은 7.4건으로 차이가 통계적으로 유의하지 않았다(p = 0.31, 95% 신뢰구간 −1.9 ~ 0.7). 사후 검정력 분석 결과 이 표본에서 탐지 가능한 최소 효과 크기는 d = 0.83이었다.

면담 자료에서 실험 집단 참여자 24명 중 17명이 에이전트 피드백을 읽고 이유를 이해하려 했다고 응답했으나, 9명은 제안된 수정을 확인 없이 그대로 적용한 경우가 있다고 보고했다.

## 5. 논의

실시간 리뷰 에이전트는 12주 동안 산출물 수준의 품질 지표를 뚜렷하게 개선했다. 반면 도구를 제거한 조건에서의 결함 밀도 차이는 확인되지 않았다.

이 결과의 해석에는 몇 가지 경계가 있다. 첫째, 전이 과제의 귀무 결과는 효과가 없다는 증거가 아니라 이 표본 규모에서 중간 크기 이하의 효과를 탐지할 수 없었다는 의미다. 팀 단위 배정으로 유효 표본이 9개 팀에 가깝기 때문에 검정력이 낮다.

둘째, 배정이 무작위가 아니므로 기업 간 기존 코드 품질 문화 차이가 결과에 섞여 있을 수 있다. 임의효과로 기업을 통제했으나 관측되지 않은 팀 수준 차이는 남는다.

셋째, 전이는 12주차 단일 시점에서 한 번 측정되었다. 학습 전이가 더 긴 시간에 걸쳐 나타난다면 본 설계는 이를 포착하지 못한다.

넷째, 전이 과제는 400줄 규모의 통제된 기능 구현이며, 실제 업무에서의 설계 판단이나 장기 유지보수 품질과는 다른 구성개념이다.

## 6. 결론

실시간 코드 리뷰 에이전트는 관찰 기간 동안 리뷰 반려율과 결함 재발률을 낮췄으나, 도구 없는 조건에서의 전이 효과는 본 연구의 설계와 표본으로는 확인되지 않았다. 더 긴 관찰 기간과 더 많은 팀을 포함한 후속 연구가 필요하다.

## 감사의 글

연구에 참여해 준 세 기업의 개발 조직과 익명 평가자 두 분께 감사드린다. 본 연구는 교내 연구비의 지원을 받았다.
